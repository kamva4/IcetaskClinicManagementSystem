# Clinic Management System - Java Project

## Overview
A console-based Clinic Management System developed in Java using NetBeans IDE and Maven. The system manages patient registration, appointment scheduling, and reporting for a general clinic.

This project was developed to meet academic requirements for OOP principles: Encapsulation, Inheritance, Abstraction, and Polymorphism.

## Features
- **Patient Registration:** Register General and Specialist patients with validation
- **Duplicate Check:** Prevents duplicate Patient IDs
- **Appointment Scheduling:** 15 fixed slots (Mon-Wed, 9AM-3PM), one appointment per patient
- **Double Booking Prevention:** Time slot can only be booked once
- **Search Function:** Search patient by ID
- **Sorting:** Sort by Last Name and by Patient ID using Comparator
- **Reports:** View all patients and appointments

## Technologies
- Java JDK 17+
- NetBeans IDE
- Maven Project
- JUnit 5 (Jupiter) for Unit Testing
